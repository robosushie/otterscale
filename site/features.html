What ships today

A console around Headscale.

Single tenant, SQLite, local login plus TOTP. Users join with official Tailscale clients. Funnel, billing, and a custom VPN app are out of scope.

Deploy ▸

Modules

Each card is a console area you can open after setup.

Machines

List nodes, generate pre-auth keys, copy tailscale logout then tailscale up.

Network Apps

Publish a mesh address on a hostname. Edge reverse-proxies onto 100.x. Not Funnel.

Users and roles

Owner, Super admin, Admin, Member. Local credentials always on; OIDC when three env vars are set.

Workspaces

Isolation unit. Maps to a Headscale ACL group. Peers that share a workspace can see each other.

Tags

Orthogonal labels such as prod, uat, and dev. They are not isolation by themselves.

Policies

Intent in the console compiles to Headscale HuJSON. Apply from Settings → Policy file.

Audit

System and network logs with an append-only hash chain for control-plane actions.

Keys

Reusable or one-shot auth keys bound to workspaces and tags. Edge uses a tag:edge key.

Architecture

Browser and clients hit edge. Console talks to Headscale. Apps hop onto the mesh via tsnet.
