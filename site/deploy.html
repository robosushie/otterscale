Otterscale Stack

One Compose file. Pull and run.

Images live on GHCR. After Headscale is healthy, bootstrap writes API keys and AUTH_SECRET so you do not paste them by hand. Set OTTERSCALE_DOMAIN wherever TLS terminates in front of Headscale.

Download stack ▸ Env example

Generic Docker host

This is the canonical path: a VM with Docker Compose, ports 80/443, and a volume disk.

cp otterscale-stack.env.example .env
# set OTTERSCALE_DOMAIN and AUTH_URL for production
docker compose -f otterscale-stack.yaml --env-file .env up -d

Local default login-server is http://127.0.0.1:8080. Console: https://console.localhost. Publish images first via Actions → Publish GHCR (pick a branch, enter a tag).

Cloud platforms

Open a platform. Compose runs on a VM everywhere it is listed as native. PaaS that cannot share volumes maps the same three images instead.

AWS EC2

Launch Ubuntu, open 80/443 (and 8080 only if you join locally on the instance). Install Docker Compose. Copy the stack file and env example onto the box.

Point a Route 53 record at the instance. Set OTTERSCALE_DOMAIN, AUTH_URL, CONSOLE_HOST, and HS_HOST to those names. Caddy in this stack uses internal TLS; put a public proxy or swap Caddy to public certs if you need a trusted browser cert.

DERP/STUN needs UDP. This stack uses the public Tailscale DERP map. Host your own relay on a second instance if you need it.

Azure Virtual Machine

Same as a generic VM. NSG: TCP 80/443. Attach a data disk and bind Docker volumes to it so SQLite and Headscale survive reboot.

Set OTTERSCALE_DOMAIN to the Headscale hostname on your DNS zone. Do not leave it empty in production or clients will be told to use loopback HTTP.

GCP Compute Engine

Create a VM, allow http/https in the VPC firewall, install Docker, run Otterscale Stack. Use a static IP and Cloud DNS records for console and Headscale.

Persistent disk for Docker volumes. Tag the firewall rule so only 80/443 are public; keep Headscale 8080 on localhost unless you terminate TLS elsewhere.

Akamai Linode

Marketplace Docker or a Debian image. Open 80/443 in Cloud Firewall. Copy the stack YAML, fill .env, docker compose up -d.

Linode DNS for CONSOLE_HOST / HS_HOST. Same image tags as GHCR OTTERSCALE_IMAGE_TAG.

Render

Render can run Docker Compose on a private service / VM-like instance, or one service per image. Shared volumes between services are limited.

Preferred: a Render VM (or Background Worker host) that runs this Compose file. If you split services, you lose the secrets volume — mint keys once and paste HEADSCALE_API_KEY / APPS_EDGE_AUTHKEY into each service.

Set OTTERSCALE_DOMAIN to the public Headscale URL Render gives you. Render TLS is at their edge; Headscale server_url must be that HTTPS origin.

Railway

Railway does not run this Compose file inside one empty service. Drag-and-drop Compose only creates three services; it does not share volumes, so bootstrap cannot hand keys to app/edge automatically.

Use the same GHCR images as three Railway services. Private DNS: headscale.railway.internal:8080. Attach a volume to Headscale and to the app. Generate keys with a one-off headscale apikeys create / preauthkeys create on the Headscale service, then set those variables on app and edge.

Set OTTERSCALE_DOMAIN to the public HTTPS domain you attach to Headscale. Railway has no inbound UDP for a private DERP.

Heroku

Heroku is not a Compose host and does not share volumes. This YAML will not run there as-is.

If you still want Heroku, run a VM alongside (EC2 / Lightsail / Linode) for Headscale + edge, and only put a stateless web process on Heroku — that split is not this stack. Prefer a cloud VM and the download above.

Images and tags

GitHub → Actions → Publish GHCR. Choose the branch, enter a tag such as 0.1.0 or dev. That pushes:

ghcr.io/robosushie/otterscale/app
ghcr.io/robosushie/otterscale/edge
ghcr.io/robosushie/otterscale/headscale

Semver tags also move latest. Override with OTTERSCALE_IMAGE_TAG in .env. First publish: if the workflow cannot mark packages public, open Packages and set visibility to public once.
