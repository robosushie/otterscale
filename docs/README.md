# Otterscale documentation

Otterscale is an open-source, multi-tenant team mesh control platform built on [Headscale](https://github.com/juanfont/headscale), with a polished web console, policy compiler, RBAC, audit, access workflows, CLI/SDK, and Kubernetes operator. **End users connect with the official Tailscale apps only**—no custom client.
